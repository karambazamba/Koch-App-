# A-042 SOFORT: „Familie verbinden“ klarer + Namen statt Mail-Adresse (Wortlaut 28.10.; Bild 1 und 2 nicht angekommen)

1. TEXTE ANMELDEN (Bild 1)
- Überschrift bleibt „Familie verbinden“. Unterzeile neu: „Teil Termine, Einkauf und Pinnwand mit deinen Leuten.“
- Darunter klein: „Ohne Konto bleibt alles auf diesem Handy.“
- Unter dem Knopf: „Du bekommst einen Code per Mail. Ein Passwort brauchst du nicht.“
- Keine Gedankenstriche, Haushaltsart beachten (allein: „Mit jemandem teilen“, Paar: „Zu zweit verbinden“, Familie: „Familie verbinden“).

2. NAMEN STATT MAIL-ADRESSE (Bild 2)
- Anzeigename = Name aus dem Mia-Profil (z. B. „Felix“). Nur wenn keiner da ist: beim Anlegen einmal fragen „Wie sollen dich die anderen sehen?“ (ein Feld, vorausgefüllt mit dem Teil vor dem @, großgeschrieben, ohne Punkte/Zahlen).
- Nie die Mail-Adresse als Name zeigen (Familie, Mitglieder, „erledigt von …“, Pinnwand, Einladungstext). Mail nur klein unter „Angemeldet als“.
- Haushaltsname: Standard je Haushaltsart „Familie“ / „Wir zwei“ / „Privat“; mit Nachname aus dem Profil „Familie Gabriel“. Antippen = umbenennen.
- Avatar-Kreis zeigt immer den Anfangsbuchstaben in der Personenfarbe.
- Migration: bestehende Konten mit Mail-artigem Anzeigenamen einmalig auf den Profilnamen setzen (bzw. bereinigten Teil vor @), Haushaltsname „Familie <mail>“ → Standard.
- Test: kein sichtbarer Text enthält „@“ außer „Angemeldet als“; Profilname wird übernommen; Migration.

3. EINLADUNGSLINK VERSTÄNDLICH (Ergänzung 28.10.)
- Statt „bis 11.11.“: „Link gilt 14 Tage, bis Mi, 11. Nov.“ und darunter klein „Wer ihn öffnet, gehört zur Familie. Danach einfach neu holen.“ (Datum mit Wochentag kurz, Tag, Monat kurz; „Familie“ je Haushaltsart; Laufzeit aus der vorhandenen Ablauf-Logik).
- Bei mehreren offenen Links: je Zeile „Link für Erwachsene · gilt bis Mi, 11. Nov. · 1× benutzt“ und rechts „Zurückziehen“ (Tippfläche ≥ 44 px).
- Tests: Text mit Datum und Wochentag; mehrere Links als Zeilen; Zurückziehen.
